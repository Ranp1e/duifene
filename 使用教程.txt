一、安装 Tampermonkey（篡改猴）
===============================================

Tampermonkey（俗称"篡改猴"或"油猴"）是一个浏览器扩展，
可以让你在网页上运行自定义 JavaScript 脚本。

【步骤】

1. 打开你的浏览器（推荐 Chrome、Edge 或 Firefox）

2. 访问 Tampermonkey 官网下载页面：
   https://www.tampermonkey.net/

3. 根据你的浏览器点击对应链接：
   - 如果用 Chrome 浏览器 → 点击 "Chrome" 或前往 Chrome 应用商店
   - 如果用 Edge 浏览器   → 点击 "Edge" 或前往 Edge 加载项
   - 如果用 Firefox 浏览器 → 点击 "Firefox"

4. 在应用商店页面点击"获取"/"添加扩展"/"安装"

5. 等待安装完成，浏览器右上角会出现一个 Tampermonkey 图标
  （一个方形图标，中间有两个圆点，类似 🐵 猴脸）

6. 点击该图标确认已安装成功，你会看到一个菜单

【Edge 用户特别注意】
如果 Edge 应用商店打不开，可以：
  - 先安装 "Tampermonkey Legacy" 或从 Chrome 应用商店安装
  - 安装完后需要在 Edge 地址栏输入 edge://extensions/
  - 打开左下角"允许来自其他应用商店的扩展"开关


===============================================
二、安装脚本
===============================================

【步骤】

1. 确保 Tampermonkey 已安装（浏览器右上角有图标）

2. 打开你电脑上的文件夹，找到脚本文件：
   duifene-auto-answer.user.js

3. 用鼠标将这个 .js 文件直接拖到浏览器窗口里

4. Tampermonkey 会自动识别弹出安装页面，点击"安装"按钮

5. 安装成功后，点击 Tampermonkey 图标 → "管理面板"
   你应该能看到"对分易自动答题助手"出现在列表中

【验证安装】
  - 打开任意对分易页面（https://www.duifene.com）
  - 页面右下角应出现紫色悬浮窗，显示 "🖥️ 答题日志"
  - 页面右侧应出现紫色控制面板，显示 "🤖 对分易答题"
  - 如果都出现了，说明安装成功！


===============================================
三、注册 DeepSeek 并获取 API Key
===============================================

DeepSeek 是一个 AI 大模型平台，提供 API 接口供程序调用。
本脚本需要 API Key 才能让 AI 帮你答题。
价格大约 ¥1/百万 token（答几百道题只需几分钱）。

【步骤】

1. 打开浏览器，访问 DeepSeek 官网：
   https://platform.deepseek.com

2. 点击页面上的"登录"或"注册"按钮
   - 可以用手机号注册（推荐）
   - 也可以用邮箱注册
   - 或者用微信扫码登录

3. 注册/登录后，进入控制台界面

4. 在左侧菜单找到 "API Keys"（或中文"API 密钥"）

5. 点击"创建 API Key"按钮

6. 给 Key 起个名字（随便填，比如"对分易"）

7. 点击"创建"后会显示一串以 sk- 开头的字符，类似：
   sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

8. ⚠️ 非常重要：立即复制这串字符！关闭窗口后将无法再次查看！

9. 保存好这个 Key，下一步要用


===============================================
四、配置脚本
===============================================

【步骤】

1. 打开对分易网站并登录：
   https://www.duifene.com

2. 页面右侧会有一个紫色控制面板，标题"🤖 对分易答题"

3. 在面板中找到 "🔑 DeepSeek API Key" 输入框

4. 把你在第三步复制的 sk-... 粘贴进去

5. 点击面板上的 "⚙️ 更多设置" 展开高级选项：

   📦 Model — 默认值是 deepseek-v4-pro，一般不用改
   
   ⏱️ 题间延时 — 每题切换等待时间（毫秒）
      默认 1200ms（1.2秒），如果网速慢可以调大
      
   ☑️ 答完后自动提交 — 勾选后所有题答完会自动点击"提交试卷"
   
   ☑️ 提交后返回练习列表 — 勾选后提交完会跳回试卷列表页

6. 配置会自动保存，关掉页面重开也不会丢失

【面板按钮说明】
  🚀 一键自动答题 — 开始全自动答题
  ⏸️ 暂停           — 暂停/继续答题
  📤 直接提交        — 手动点击提交试卷
  ↩️ 返回列表        — 返回练习列表页面
  🗑️ 清空缓存        — 删除本地缓存的答案


===============================================
五、开始答题
===============================================

【步骤】

1. 确保已登录对分易，并且配置好了 API Key

2. 进入你要做的试卷页面（在线练习 / 考试）

3. 确认页面正常显示了题目（能看到第一题）

4. 点击右侧面板的 🚀 "一键自动答题" 按钮

5. 观察右下角悬浮窗口，你会看到实时日志：
   📝 Q1/21 [单选题] 实现（  ）是近代以来...
   🤖 调用 DeepSeek API...
   🤖 返回 → B
   ✅ 已选: B  (来源: 🤖 AI)
   ➡️ → 第 2 题

6. 每道题大概需要 2-5 秒（AI 思考 + 网络延迟）

7. 所有题答完后终端会显示：
   ══════════════════════════════
   ℹ️ 答题完成 ✅18 ❌3 / 21
   ══════════════════════════════

8. 如果开启了"答完后自动提交"，脚本会自动点击提交

【答题卡功能】
  终端底部有一个题号网格：
  - 白色数字 = 未答题
  - 绿色数字 = 已答题（可点击跳转到该题）
  - 金色边框  = 当前正在显示的题目

【暂停功能】
  点击控制面板的"⏸️ 暂停"按钮可以随时暂停
  再次点击"▶️ 继续"会接着往下答


===============================================
六、常见问题与注意事项
===============================================

【Q：脚本不显示面板 / 终端】
  A1：检查 Tampermonkey 是否启用（图标不是灰色的）
  A2：检查脚本是否安装成功（管理面板里能看到）
  A3：检查 @match 设置：脚本匹配 *.duifene.com/*
  A4：刷新页面重试

【Q：点击答题后没反应 / 选项选不上】
  A1：确认 API Key 已填入且格式正确（以 sk- 开头）
  A2：打开浏览器 F12 → Console 查看是否有红色错误信息
  A3：确认 DeepSeek 账户有余额（新用户免费赠送额度）

【Q：API 报错 / 请求失败】
  A1：检查 API Key 是否正确复制（不要多空格）
  A2：确认 DeepSeek 账户余额 > 0
  A3：检查网络是否能访问 api.deepseek.com
  A4：在终端日志里看具体错误信息

【Q：多选题正确率不高】
  A1：v4.0 已强化多选题提示词，准确率大幅提升
  A2：多选题答案有时 AI 会犹豫，可以在终端看 AI 返回了什么
  A3：答完可以手动检查多选题（答题卡点击跳题很方便）

【Q：问答题填不进去】
  A：v4.0 已修复，支持"问答题"关键词和 UEditor 富文本编辑器

【Q：答完不想提交想检查答案】
  A：不要勾选"答完后自动提交"。答完手动检查后，点 📤 提交

【注意事项】
  ⚠️ 不要在考试期间刷新页面，会丢失进度
  ⚠️ 首次运行请在小范围试卷上测试，确认无误后再大规模使用
  ⚠️ API Key 只存储在你自己电脑上，不会上传第三方
  ⚠️ 本脚本仅用于辅助学习，请遵守学校和平台的规定
  ⚠️ DeepSeek API 按使用量计费，每道题约消耗几分钱
  ⚠️ 人机验证：部分考试可能有人机验证，如果遇到请手动完成
