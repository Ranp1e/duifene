一、安装 Tampermonkey（篡改猴）
===============================================

Tampermonkey（俗称"篡改猴"或"油猴"）是一个浏览器扩展，
可以让你在网页上运行自定义 JavaScript 脚本。

【步骤】

1. 打开你的浏览器（推荐 Edge 或 Chrome）

2. 访问 Tampermonkey 官网下载页面：
   https://www.tampermonkey.net/

3. 根据你的浏览器点击对应链接安装扩展

4. 安装完成后，浏览器右上角会出现 Tampermonkey 图标

【Edge 用户特别注意】
如果 Edge 应用商店打不开，可以：
  - 从 Chrome 应用商店安装
  - 安装完后在 Edge 地址栏输入 edge://extensions/
  - 打开左下角"允许来自其他应用商店的扩展"开关


===============================================
二、安装脚本
===============================================

【步骤】

1. 确保 Tampermonkey 已安装

2. 用鼠标将 duifene-auto-answer.user.js 文件直接拖到浏览器窗口里

3. Tampermonkey 会弹出安装页面，点击"安装"按钮
   （已安装过旧版会提示更新，确认即可）

4. 安装成功后，点 Tampermonkey 图标 → "管理面板"
   能看到"对分易自动答题助手"即可

【验证安装】
  - 打开任意对分易页面（https://www.duifene.com）
  - 会弹出"免责声明"窗口，阅读后点"我已阅读并同意"
    （每次打开页面都会显示一次，这是故意的）
  - 页面右下角出现紫色圆形悬浮球（上面写着"答"）
  - 点击悬浮球展开面板，说明安装成功！


===============================================
三、注册 DeepSeek 并获取 API Key
===============================================

DeepSeek 是一个 AI 大模型平台，本脚本需要 API Key 才能答题。
价格大约 ¥1/百万 token（答几百道题只需几分钱）。

【步骤】

1. 访问 https://platform.deepseek.com 并注册/登录

2. 左侧菜单找到 "API Keys" → 点击"创建 API Key"

3. 创建后显示一串 sk- 开头的字符：
   ⚠️ 立即复制保存！关闭后将无法再次查看！


===============================================
四、配置脚本
===============================================

【步骤】

1. 打开对分易网站并登录，点击右下角悬浮球展开面板

2. 点"设置"标签页，把 sk-... 粘贴到"DeepSeek API Key"

3. 建议点一下"测试 API"按钮，显示"API 正常"就说明配置成功

4. 其他设置（一般保持默认即可）：

   📦 模型 — 默认 deepseek-chat，不用改
   ⏱️ 题间延时 — 默认 2000ms，网速慢可调大
   ☑️ 跳过已作答的题目 — 默认开，之前答过的题不再重复答
   ☐ 答完后自动提交 — 默认关；开启后提交前仍会弹窗让你确认
   ☑️ 提交后返回练习列表 — 默认开
   ☑️ 启用快捷键 — 默认开

5. 配置自动保存，关掉页面重开也不丢失
   （v6 老用户的 Key 和答案缓存会自动迁移过来）


===============================================
五、开始答题
===============================================

【步骤】

1. 进入你要做的试卷页面，确认能正常看到题目

2. 点面板的 🚀 "开始自动答题"（或按 Alt+Q）

3. "运行"标签页可以看到：
   - 进度条和统计：✅成功 ❌失败 ⏭️跳过 🤖API次数 🔤token数
   - 答题卡：绿=已完成 · 红=失败 · 黄框=当前题
     （没在开始答题时，点击格子可以跳题）

4. "日志"标签页有详细过程记录，出问题可点"导出日志"发给开发者

5. 随时可 ⏸️ 暂停 / ▶️ 继续 / ⏹️ 停止

6. 全部答完后，脚本默认不提交。检查一遍后：
   - 手动点页面的"完成并提交"，或
   - 点面板的 📤 "提交试卷"（会弹窗确认）

【问答题说明】
  问答题答案会写入编辑器，并通过真实保存接口提交到服务器，
  日志显示"问答题已保存到服务器 ✅"才算成功。
  如果保存失败，脚本会自动暂停，你可以手动检查后点"继续"重试本题。


===============================================
六、常见问题与注意事项
===============================================

【Q：看不到悬浮球】
  A1：检查 Tampermonkey 是否启用、脚本是否在管理面板里
  A2：确认网址是 www.duifene.com 开头，刷新页面
  A3：如果之前点过免责声明的"不同意"，刷新页面会重新显示

【Q：点了开始没反应】
  A1：必须先在"设置"里填 API Key
  A2：必须先进到试卷答题页（能看到题目和"下一题"的页面）
  A3：免责声明要先点"我已阅读并同意"

【Q：API 报错】
  A1：用设置里的"测试 API"按钮定位问题
  A2：检查 Key 是否复制完整、DeepSeek 账户是否有余额

【Q：问答题答了但页面没保存】
  A：v7 已修复（旧版保存接口参数写错了）。现在以日志里
     "问答题已保存到服务器 ✅"为准；看到红色报错就点暂停检查。

【Q：填答案了想检查再提交】
  A：默认就是不自动提交。答完后用答题卡跳题逐题检查，
     确认无误再手动提交。

【注意事项】
  ⚠️ 首次使用请先在小范围试卷上测试
  ⚠️ 不要同时在多个标签页运行答题（脚本会检测并阻止）
  ⚠️ API Key 只存在你自己电脑上，不会上传第三方
  ⚠️ 本脚本仅用于辅助学习，请遵守学校和平台的规定
  ⚠️ DeepSeek API 按量计费，每道题约几分钱
  ⚠️ 遇到人机验证请手动完成
